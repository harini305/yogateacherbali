# YogaFX Teacher Training – website (Phase 2)

Frontend-only redesign of https://yogafxteachertraining.com, built with Next.js (App Router, JavaScript), React, GSAP + ScrollTrigger and CSS Modules. Source content and assets come from the Phase 1 audit in `docs/source-audit/`.

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run images     # regenerate public/images from docs/source-audit/assets-original (needs Python + Pillow)
```

## Where things live

| What | Where |
|---|---|
| Dates, contact details, payment links, online-course price, nav | `lib/site.js` (single source of truth) |
| Bali course fee | `masterclass.fee` in `lib/site.js`, currently `null` (published prices conflict; the UI shows "confirmed on enquiry") |
| Design tokens (colours, two font families, type scale, spacing) | `app/globals.css` |
| Scroll motion (reveals, timelines, parallax) | `components/Motion.js`, mounted per page by `app/template.js` |
| Image derivatives + dimensions manifest | `public/images/`, `lib/images.generated.js` (generated by `scripts/build-images.py`) |
| Old WordPress URL redirects | `next.config.mjs` |

Image optimisation is disabled (`images: { unoptimized: true }`); responsive WebP derivatives are pre-generated instead.

Payments, enrollment forms and the interest form are not rebuilt: buttons link to the existing pages on the current WordPress site.
